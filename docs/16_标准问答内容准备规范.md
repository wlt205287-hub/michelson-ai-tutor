# 标准问答内容准备规范

更新日期：2026-07-15

## 1. 用途

本文档用于准备“标准问题 + 固定回答”数据。

后端命中标准问题后，将直接返回审核过的 Markdown 答案，不再交给大模型改写，从而保证每次输出逐字一致。

本文档只规定内容格式。

## 2. JSON 格式

文件使用 UTF-8 编码，结构如下：

```json
{
  "items": [
    {
      "id": "beam_splitter_role",
      "aliases": [
        "分束镜的作用是什么",
        "分光镜的作用是什么",
        "分束镜有什么作用"
      ],
      "answer_markdown": "分束镜在迈克耳孙干涉仪中承担**分束与合束**作用。\n\n它先将入射光分成两路；两路光分别传播并反射后，再次在分束镜处合束并形成干涉信号。"
    },
    {
      "id": "fringe_in_out_principle",
      "aliases": [
        "动镜移动为什么会出现条纹吞吐",
        "为什么会有条纹冒出和缩进",
        "条纹吞吐是怎么产生的"
      ],
      "answer_markdown": "动镜移动 $\\Delta d$ 时，干涉光程差变化 $2\\Delta d$。若通过的条纹数为 $N$，则满足：\n\n$$\n2\\Delta d=N\\lambda\n$$"
    }
  ]
}
```

## 3. 字段规则

| 字段 | 要求 |
| --- | --- |
| `id` | 唯一英文标识，只使用小写字母、数字和下划线 |
| `aliases` | 可以触发同一固定答案的不同问法 |
| `answer_markdown` | 审核后的完整固定答案 |

### `aliases`

- 所有别名必须表达完全相同的意图；
- 同义术语应分别登记，例如“分束镜”和“分光镜”；
- 不必重复登记只有空格或句末标点不同的问法；
- 不要使用“分束镜”“为什么”等过短、过宽泛的别名；
- 含义不同的问题必须拆成不同条目。

例如，“分束镜的作用是什么”不应与以下问题共用答案：

```text
分束镜为什么能分光
分束镜损坏了怎么办
分束镜和补偿镜有什么区别
如何调整分束镜
```

### `answer_markdown`

- 概念、公式、符号和单位必须准确；
- 回答应完整、简洁，不扩展无关内容；

JSON 中的换行写成 `\n`，LaTeX 反斜杠写成双反斜杠，例如 `\\Delta`、`\\frac`。
