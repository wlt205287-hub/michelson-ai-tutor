# 真实调用演示

这组材料展示作者独立实现的 Agent 后端如何处理三个合成输入。输入不是学生作业，输出来自 2026-09-14 的真实模型调用，不是手写的理想答案。阅读这些静态材料不需要运行服务或填写密钥。

> 本次只整理展示材料，不修复业务问题。报告检查仍有 mask 遗留要求；题目 q3 存在语义重复的干扰选项。保留原始输出，是为了展示系统实际表现和已知边界，不表示所有内容都正确。

## 1. 三个案例

| 案例 | 展示的后端能力 | 观察结果 | 阅读入口 |
| --- | --- | --- | --- |
| 引导式问答 | 请求级教学策略、阶段化 Prompt、待学生回复状态 | 给出关键公式后追问往返光程，没有直接结束为最终答案 | [案例说明](cases/01-guided-tutoring.md)、[完整回答](results/tutor.md) |
| 预习出题 | 出题意图门控、Schema 校验、校验后流式返回 | 3 道选择题、2 道简答题；含答案与评分要点 | [案例说明](cases/02-quiz-generation.md)、[原始题目 JSON](results/quiz.json) |
| 报告检查 | 报告量规 Prompt、SSE、建议分与人工复核提示 | 对刻意缺材料的片段返回诊断；同时暴露 mask 知识不同步 | [案例说明](cases/03-report-review.md)、[完整回答及风险提示](results/report.unreviewed.md) |

## 2. 证据与解释

| 请求 | HTTP / success | 单次总耗时 | SSE 观察 |
| --- | --- | --- | --- |
| 问答 | 200 / true | 27.91 秒 | 本例使用非流式接口 |
| 出题 | 200 / true | 68.49 秒 | 1 个 meta、1 个完整 delta、1 个 done |
| 报告 | 200 / true | 84.23 秒 | 1 个 meta、1378 个 delta、1 个 done |

两个流式案例的增量拼接均与最终答案一致，且都没有 error 事件。详见 [请求汇总](evidence/run-summary.json) 和 [SSE 一致性检查](evidence/stream-checks.json)。出题只输出一个完整 delta，是现有“先缓冲并校验，再发布题目”的行为，不应描述成逐字实时出题。

耗时只是这三个不同请求各自的一次观测，不是平均延迟、首字延迟或性能承诺。该记录不提供 token 用量、模型成本、准确率或用户规模。一次 API 请求内部可能包含分类或修复等多次模型调用，本材料不声称本轮触发了所有回退分支。

模型服务由作者本地配置，本次记录没有采集提供商和模型标识，也没有读取配置文件。因此这些材料是输入输出快照，不是模型效果可严格复现的评测集。RAG、视觉、扫描 PDF、设备控制都不能用这三个文本案例证明已经实测。

## 3. 面试时如何讲

1. **先讲边界**：这是团队实验平台中的独立 Agent 后端，作者负责后端，桌面界面和实验算法不属于本仓库。
2. **展示问答**：指出 `pre_lab`、`guided` 和引导等级如何影响回答，并展示 `need_student_reply=true` 的客户端约定。
3. **展示出题**：说明为什么模型输出不能直接透传，要经过固定题型、字段和数量校验；同时说明 Schema 无法替代语义审核。
4. **展示报告**：说明增量输出、诊断结构和教师复核边界；主动指出 mask 是知识版本同步问题，目前未修复。
5. **回到工程证据**：真实调用说明链路可用，mock 回归覆盖异常和兼容分支；两者都不能直接推出教学效果提升。

可用的一句话介绍：

> 我独立实现了实验 AI 助教后端，从接口和教学策略编排到结构化出题、报告检查与流式输出；这三个案例分别展示了引导、结构校验和材料诊断，也记录了生成质量与知识同步的现有限制。

## 4. 本地重跑

先按 [主 README](../README.md) 安装依赖、配置自己的模型并启动服务。以下命令在仓库根目录执行，使用本目录保存的合成输入；可能产生模型费用。

```powershell
curl.exe -sS http://127.0.0.1:8000/api/agent/chat -H "Content-Type: application/json" --data-binary "@showcase/inputs/chat.json"
curl.exe -N http://127.0.0.1:8000/api/agent/chat/stream -H "Content-Type: application/json" --data-binary "@showcase/inputs/quiz.json"
curl.exe -N http://127.0.0.1:8000/api/agent/report-check/stream -H "Content-Type: application/json" --data-binary "@showcase/inputs/report.json"
```

重新运行可能得到不同内容。不要覆盖旧快照后仍沿用旧耗时和验证结论。

## 5. 发布边界

- `inputs/` 保存三个原始合成请求；`responses/` 保存三个完整响应包络；`results/` 提供可读结果与解析后的题目。
- 问答和报告 Markdown 只添加演示标题、边界提示及正文起止标记，模型正文不删改；题目 JSON 只格式化，不替换答案或选项。
- `evidence/` 是本轮汇总及由本地原始 SSE 事件机械统计的结果，不含请求头、完整日志、密钥、模型配置或私人文件路径。
- `showcase/` 不受 `outputs/` 的忽略规则影响，可随代码提交；不是已经完成 Git 提交或上传。
- 团队约定、教学图片和知识材料的授权仍须按 [公开检查清单](../PUBLICATION_CHECKLIST.md) 确认。脱敏整理不能替代授权审核。
