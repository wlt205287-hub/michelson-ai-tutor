# 案例 3：报告检查与已知误报

> **未通过完整教学准确性验收。** 本案例展示报告检查工作流，也保留已复现的 mask 遗留要求。不要把输出直接当作当前实验的提交规范或正式评分结果。

## 场景与输入

输入是一段刻意不完整的合成报告：说明连续扫描、稳定帧和 ROI、时间去均值、Hann 窗、主频提取及相对高度换算，但明确没有提供真实原始帧、结果或误差分析，并要求模型不要编造数据。

接口为 `POST /api/agent/report-check/stream`。完整输入见 [report.json](../inputs/report.json)。本例没有上传 PDF 或图片，也没有提供 `quiz_context`，不能用它证明视觉检查或习题作答检查已经实测。

## 实际输出

模型返回总体评价、发现的问题、问题原因、修改建议、初步评分、是否需要教师复查六个部分。它要求补充采集参数、灰度时间曲线、频谱、相位和高度结果等证据，并给出 25/100 的建议分及教师复查提示。

该分数来自刻意缺材料的合成片段，不代表任何学生成绩，也不能证明评分公正或准确。完整内容见 [带风险提示的报告回答](../results/report.unreviewed.md) 和 [原始 JSON 响应](../responses/report.json)。

HTTP 200、`success=true`，总耗时 84.23 秒。SSE 含 1378 个 delta，拼接内容与 done 的最终答案一致，且没有 error 事件。见 [流式检查证据](../evidence/stream-checks.json)。

## 复现的 mask 问题

原始输出包含以下要求：

> 提供质量图或 mask、包裹相位图、二维展开相位图，并说明 mask 是否经过平滑、阈值、形态学处理。

原实验的 data_process 主流程已停用 mask，这一要求不应被当作报告的必需项。当前 Agent 的部分 Prompt、基础知识库与 RAG 文本仍有旧说明，是需要后续核对的知识版本不一致。报告中的其他教学建议也未逐条完成专家验收。

作者本轮选择暂不修复，展示材料没有删除这段误报来制造“完美结果”。后续修复应同步知识与提示词并回归同一输入，而不是只在展示页改掉模型原文。
